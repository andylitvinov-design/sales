# PsiTrends Soul Design

## Intent

Refine the canonical bilingual PsiTrends client homepage without changing its three-pillar information architecture, tracking, routing, or Joomla delivery boundary.

## Composition

The homepage opens with an editorial split hero: real Andrey portrait first, archway as a secondary atmospheric fragment, and one WhatsApp session CTA. A concise author note follows immediately. The three existing paths become distinct chapters: inward consultation with a portrait detail, study with an existing archival Egyptian-object image, and a typographic clay workshop field that leads to legitimately published participant stories rather than invented group photography.

## Guardrails

- Keep EN/RU routes, canonical and hreflang output, contact tracking, GA4 consent, and production asset URLs unchanged in purpose.
- Add no dependency or tracker.
- Use CSS-drawn arrows in the client generator; never emit Unicode arrow glyphs in client CTAs.
- Use the existing first-party archival image URL in production; copy its tracked local mirror only into preview output for browser QA.
- Tune mobile 390x844 and 430x932 independently from desktop rather than applying a global padding reduction.
