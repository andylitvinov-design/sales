# Sales Pages

Набор маркетинговых лендингов и связанных quality-check инструментов для быстрых промо-страниц и офферов.

## Project Role

`sales` — это runtime-витрина для продающих страниц: здесь хранятся реальные HTML/CSS лендинги, которые можно быстро открыть, проверить, править и деплоить.

Граница ответственности:

- `andrey-system` = источник истины по бизнес-упаковке, офферам, продуктовой лестнице, brand language и агентным инструкциям.
- `alchemy-method` = источник истины по методу, диагностике, У-Син, ДАО, гомеопатии, отчётам и структуре консультаций.
- `sales` = публикационный слой: конкретные лендинги, визуальная подача, CTA, секции, тексты страницы, deploy и quality-check.

Правило работы: не придумывать метод и офферы заново внутри `sales`; брать смысл из `andrey-system`, а здесь превращать его в понятную продающую страницу.
